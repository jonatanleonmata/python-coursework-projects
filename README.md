## Running the programs

Install Python 3, open the project folder, and use the command in its README. The programs use Python's built-in features and standard library, with no additional packages. Verification was performed with Python 3.14.5.

## Academic context

These are coursework examples. Original assignment filenames and course headers have been preserved. Each project README explains the program's features and current input assumptions.
